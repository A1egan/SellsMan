A1eG4n工作台 · 跟进CRM v2
============================

一、如何打开
  双击 index.html 即可在浏览器中使用（建议 Chrome / Edge）。
  manga-bg.jpg 需要与 index.html 放在同一目录。

二、本版新增
  1. 下次跟进时间：每位学员可设置具体日期/时间。
  2. 下次跟进动作：例如“问99体验效果 / 邀约直播 / PV激活 / 处理价格异议”。
  3. 今日任务队列：顶部自动统计“今日 / 逾期 / 未来 / 未安排”，点击即可筛选。
  4. 今日有效沟通：记录一次沟通结果后自动计数，默认目标 20 次/天。
  5. 沟通记录：每次跟进可记录结果，并保留最近沟通历史。
  6. 快捷排期：明天 / 3天后 / 7天后 / 25号直播后。
  7. 卡片直接显示下次跟进时间与动作，逾期任务红色提醒。
  8. 导出 CSV 会同时导出最近结果、下一步动作、下次跟进等字段。

三、推荐日常工作流
  1. 每天先看顶部“逾期”和“今日”。
  2. 点击学员卡片，查看备注、标签与历史。
  3. 微信沟通后选择“沟通结果”，填写下一步动作与时间。
  4. 点击“记录本次沟通并安排下一步”。
  5. 系统会自动把该学员排入下一次任务队列。

四、数据存放
  当前版本仍使用浏览器 localStorage：
    - sales_followup_data_v3  学员数据
    - sales_tags_v1           标签数据
  数据只保存在当前浏览器/当前站点中。

五、备份 / 恢复
  - “备份”：下载包含学员、标签、跟进历史的 JSON。
  - “恢复”：导入 JSON 并覆盖当前数据。
  - 建议升级或换电脑前先备份。

六、重要说明
  目前版本是“单机/单浏览器 CRM”。如果部署成多人共用版本，需要把 localStorage 改成云数据库并增加登录/权限，否则不同电脑不会自动共享数据。
